# T1: port to the ESP32 T5-4.7 and bring it up — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the T5 board choice the LilyGo T5-4.7 on a classic ESP32 (DT9) and put it on its feet. The panel shows the dashboard through stock epdiy, with every update a clean one. The ESP32's own clock keeps time (DT10). The console runs over the CH9102 (DT11). The board deep-sleeps with its rails off. Refresh times, the slow clock's drift and the sleep current are measured.

**Architecture:**
- **Board choice.** The T5 becomes `REFLBO_BOARD_T547`, with its own ESP-IDF target, `esp32`.
- **Chip-specific code** sits behind ESP-IDF's feature macros: the console (UART instead of USB-JTAG), the deep-sleep wake (ext0 plus ext1 ALL_LOW), CPU power-down in light sleep, and the ADC's calibration scheme.
- **The panel.** epdiy runs its own ESP32 I2S path with its `epd_board_lilygo_t5_47` board definition, plus our LUT patch. Our `epaper` component rests the shift register and holds its lines through deep sleep. `display_t547.c` brings epdiy up only for each clean update.
- **The clock.** `rtcchip_t547.c` is the system clock itself.

**Tech Stack:** ESP-IDF v5.5.5 (C17, targets esp32s3 and esp32), epdiy 2.1.3 (LGPL-3.0-or-later), Unity host tests, Python unittest.

**Spec:** [`docs/specs/2026-10-06-t5-board-design.md`](../specs/2026-10-06-t5-board-design.md) r3 (approved 2026-10-07): §2, §4.1–§4.6, §5.1, §5.2, §5.4, §8, §9, §10.2, §11 T1. This plan supersedes [`2026-10-07-t1-bring-up.md`](2026-10-07-t1-bring-up.md). That plan's tasks 1–5 ran on the S3 assumption; Task 1 here removes what the ESP32 board doesn't use.

## Global Constraints

- **Workspace:** only `~/reflbo-t5`. `upstream` is fetch-only.
- **Toolchain:** ESP-IDF v5.5.5 through `tools/idf.sh`. The T5 builds with `REFLBO_BOARD=t5`, for the `esp32` target, in `build-t5/`.
- **RLCD unchanged:** the RLCD build behaves as before and its 101 goldens stay byte-identical. After every task, `ctest` passes and `git status --porcelain test/host/golden` prints nothing. RLCD-only code paths keep their exact calls: chip-specific branches add an `#if` for the ESP32 and leave the S3's line as it was.
- **Clean builds:** both boards build with no warnings after every task in which the T5 is expected to build (from Task 2 on).
- **Standing symbol checks** (T0 review), after every task that touches firmware. Each greps its own file, because this shell's `grep` can reorder output across files:
  - the T5 image has no `st7305_`, `shtc3_`, `pcf85063_` or `write_codec` symbols;
  - the RLCD image has no `epd_`, `epaper_` or `i2s_bus` symbols;
  - each `build*/config/sdkconfig.h` names its own board and target.
- **CMake:** a component's `REQUIRES` never depend on the board; only `SRCS` do.
- **epdiy:** keeps its LGPL headers. Every change to it is listed in `components/epdiy/PATCHES.md` and marked `reflbo patch Pn` in the code.
- **No vendor code:** nothing is copied from LilyGo's GPL-3.0 repository; only facts are used.
- **The two boards:**
  - The RLCD board is never flashed (DT8).
  - The T5 is `/dev/cu.usbserial-52D60046741`, MAC `34:ab:95:5e:5d:58`. Every T5 command names that port; if the name changes, the MAC decides.
  - Nothing on the T5 is erased or overwritten before the factory flash is backed up and the owner says yes (AGENTS.md rule 3).
- **Resets cost the time.** A reset through EN (`--reset`, esptool, the RESET button) wipes the T5's clock, as a power-off does. The bring-up sets the time again after one.
- **Commits:** Conventional Commits, no trailers, no AI attribution. AGENTS.md §10 changes with each new command, component or seam.

## Review Focus

1. **The RLCD build changing through the chip guards.** Expectation: every `#if CONFIG_IDF_TARGET_ESP32` / `SOC_*` / `CONFIG_ESP_CONSOLE_*` branch keeps the S3's original line as its `#else`. Task 2's review step reads each one, and the RLCD's goldens and symbol checks stay as they are.
2. **The T5 never waking from deep sleep,** or waking at once. Expectation: KEY and BOOT's role each wake it, a held button is left out, and the timer always wakes it. Task 5 runs deep-sleep cycles and simulated buttons; the physical buttons wait for access.
3. **The shift register left so that rails switch on in sleep or at boot.** Expectation: "all off" at boot and after every update, with clock and data held low in deep sleep. Task 3's test pins the word; Task 5 measures the sleep current.
4. **Internal RAM running out during an update with Wi-Fi up.** Expectation: the update still happens, with the LUT in PSRAM if needed. Task 5 runs a clean update in config mode and reads the lowest free internal RAM.
5. **The clock after a reset or power-off.** Expectation: it reads invalid, and the app asks for the time or syncs; nothing shows a 1970 clock as valid. Task 4's test pins the validity rule; Task 5 resets the board and checks `rtc get`.

## Not in T1

- Fast updates, the clean counter and its setting, the previous frame across deep sleep, night sleep's moon: T4.
- Grayscale: T2.
- The 960×540 UI: T3. Until then the RLCD's 400×300 frame sits in the panel's middle.
- The third side button (IO39): a later proposal.
- More frequent time syncs: proposed to the owner only if Task 5's drift calls for it.

```c
#include "epaper_board.h"

#include "board_pins.h"
#include "driver/gpio.h"
#include "epaper_sr.h"
#include "esp_check.h"

static const char *TAG = "epaper";

/* Shifts the word out, first bit first, and latches it on the strobe's rising edge. */
static void push(uint8_t word)
{
    gpio_set_level(BOARD_PIN_SR_STR, 0);
    for (int bit = 7; bit >= 0; bit--) {
        gpio_set_level(BOARD_PIN_SR_CLK, 0);
        gpio_set_level(BOARD_PIN_SR_DATA, (word >> bit) & 1);
        gpio_set_level(BOARD_PIN_SR_CLK, 1);
    }
    gpio_set_level(BOARD_PIN_SR_STR, 1);
}

void epaper_board_idle(void)
{
    gpio_config_t io = {
        .pin_bit_mask = BIT64(BOARD_PIN_SR_DATA) | BIT64(BOARD_PIN_SR_CLK) | BIT64(BOARD_PIN_SR_STR),
        .mode = GPIO_MODE_OUTPUT,
    };
    ESP_ERROR_CHECK(gpio_config(&io));
    epaper_sr_t off = epaper_sr_off();
    push(epaper_sr_word(&off));
    gpio_set_level(BOARD_PIN_SR_CLK, 0);
    gpio_set_level(BOARD_PIN_SR_DATA, 0);
    gpio_sleep_sel_dis(BOARD_PIN_SR_CLK); /* light sleep keeps them driven (AGENTS.md gotcha 19) */
    gpio_sleep_sel_dis(BOARD_PIN_SR_DATA);
    gpio_set_direction(BOARD_PIN_SR_STR, GPIO_MODE_INPUT); /* its pull-up keeps the strobe high */
}

esp_err_t epaper_board_prepare_deep_sleep(void)
{
    ESP_RETURN_ON_ERROR(gpio_hold_en(BOARD_PIN_SR_CLK), TAG, "hold clock");
    ESP_RETURN_ON_ERROR(gpio_hold_en(BOARD_PIN_SR_DATA), TAG, "hold data");
    gpio_deep_sleep_hold_en();
    return ESP_OK;
}

void epaper_board_release_hold(void)
{
    gpio_deep_sleep_hold_dis();
    gpio_hold_dis(BOARD_PIN_SR_CLK);
    gpio_hold_dis(BOARD_PIN_SR_DATA);
}
```

```c
/* epdiy is up only while the panel updates: its LUT and line queues want ~80 KB of internal RAM, which
 * Wi-Fi needs the rest of the time (T5 spec §5.2). */
static void panel_up(void)
{
    epd_init(&epd_board_lilygo_t5_47, &ED047TC1, EPD_OPTIONS);
    if (!s_hl_ready) {
        s_hl = epd_hl_init(NULL); /* the display's own waveform: epdiy_ED047TC1 */
        s_hl_ready = true;
    }
    uint32_t internal = (uint32_t)heap_caps_get_free_size(MALLOC_CAP_INTERNAL);
    if (s_stats.min_internal == 0 || internal < s_stats.min_internal) {
        s_stats.min_internal = internal;
    }
    epd_poweron();
}

static void panel_down(void)
{
    epd_poweroff();
    epd_deinit();
    epaper_board_idle();
}

/* The panel to white from whatever it shows, flashing, with epdiy's buffers to match. */
static void clear_to_white(void)
{
    epd_clear();
    memset(s_hl.back_fb, 0xFF, PANEL_W / 2 * PANEL_H);
    epd_hl_set_all_white(&s_hl);
}

static esp_err_t clean_update(const gfx_fb_t *fb)
{
    int64_t start = now_ms();
    panel_up();
    int64_t up = now_ms();
    clear_to_white();
    int64_t cleared = now_ms();
    epaper_frame_blit_1bpp(fb, epd_hl_get_framebuffer(&s_hl), PANEL_W, PANEL_H, FB_X, FB_Y);
    enum EpdDrawError err = epd_hl_update_screen(&s_hl, MODE_GC16, TEMPERATURE_C);
    int64_t drawn = now_ms();
    panel_down();
    s_stats.updates++;
    s_stats.last_ms = (uint32_t)(now_ms() - start);
    ESP_LOGI(TAG, "clean update: up %lld ms, clear %lld ms, GC16 %lld ms, %lu ms in all; internal RAM %lu free",
             (long long)(up - start), (long long)(cleared - up), (long long)(drawn - cleared),
             (unsigned long)s_stats.last_ms, (unsigned long)s_stats.min_internal);
    ESP_RETURN_ON_FALSE(err == EPD_DRAW_SUCCESS, ESP_FAIL, TAG, "epdiy draw error 0x%x", (unsigned)err);
    return ESP_OK;
}
```
